# Compact context handover

Rewrite your own notes/<id>-context.md when useful, replacing outdated details.
Keep it short (about forty lines), with no private details and no transcript dump.

```text
# <id> context — updated YYYY-MM-DD

## Mission
- Fictional exercise: update a demo checklist.

## Current decisions
- State the owner's current direction briefly.

## Open threads
- Task id, next step, dependency and relative file path.

## Lessons
- One reusable lesson per line.
```

After a substantive handover, one fyi board entry is enough. Start new work from the context file, not a replay of old chats.
